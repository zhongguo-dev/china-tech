## Featured developments

### Atrex Kernel Agent 0.4.0 introduces supervised GPU kernel optimization

**Original publication:** 2026-11-02

Atrex 0.4.0 introduces the Light workflow and modular provider architecture for GPU-kernel optimization with coding agents. An independent Supervisor controls correctness tests, source snapshots, same-allocation ABBA latency comparisons and candidate promotion. The release adds native CUDA manifests, multi-file sources and improved recovery, while migration from v0.3.0 requires workflow and workspace changes. Performance and token-savings claims remain publisher-reported.

**Original sources:** [Atrex technical release notes](https://github.com/alibaba/atrex-kernel-agent/blob/v0.4.0/docs/releases/v0.4.0.md) · [Atrex v0.4.0 original release](https://github.com/alibaba/atrex-kernel-agent/releases/tag/v0.4.0)

### Meituan LongCat-2.5 details verifiable agent training and multimodal infrastructure

**Original publication:** 2026-11-02

Meituan's November 2 report describes a natively multimodal LongCat-2.5 model for long-horizon tasks, including complex codebase development. Its engineering account covers executable coding-task construction, fail-to-pass and pass-to-pass tests, asynchronous partial reinforcement-learning rollouts, and accelerator-aware long-context training and inference. Performance comparisons and throughput improvements are Meituan's own measurements, not independent benchmarks. This is distinct from the Meituan AI Coding article covered in Radar #002.

**Original sources:** [Meituan LongCat-2.5 technical report](https://tech.meituan.com/2026/11/02/Meituan-LongCat-2.5.html)

### Baidu releases ERNIE 5.5 Flash Base model weights and hybrid attention design

**Original publication:** 2026-11-05

Baidu released FP8 and BF16 pretrained base weights for ERNIE 5.5 Flash Base, a sparse MoE model with 280B total and about 14B active parameters. Its original architecture report describes compressed attention, selective full-context layers, and SGLang/vLLM-serving pathways. The 128K training context is distinct from configurations supporting up to 1M tokens in inference. This is a base checkpoint, not an instruction-tuned chat model, and the weights use a dedicated ERNIE model license. Benchmark comparisons are publisher-provided.

**Original sources:** [Baidu model card and weights](https://huggingface.co/baidu/ERNIE-5.5-Flash-Base) · [ERNIE 5.5 Flash Base original release](https://ernie.baidu.com/release/ernie-5-5-flash-base)

### Tencent announces Hunyuan Hy4 vision and computer-use capabilities

**Original publication:** 2026-11-04

Tencent announced Hunyuan Hy4 on November 4 with visual understanding and computer-use tools for graphical and command-line workflows. The company described API availability and planned to release downloadable weights and a system card later. This is an announcement of model capabilities and hosted access, not evidence that open weights had already been released. Performance and safety assessments remain publisher-reported.

**Original sources:** [Tencent official Hy4 announcement](https://www.tencent.com/zh-cn/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/)
