## 重点技术进展

### 1Panel 2.5.0 重构 Linux 服务器的 GPU 与 vLLM 运维功能

**原始发布日期：**2026-11-11

1Panel 于 11 月 11 日发布 2.5.0，对 Linux 管理平台中的 GPU、vLLM 和模型服务管理进行重构。官方说明列出了 GPU 状态与 Token 吞吐量视图、模型服务控制、MCP 管理、容器更新流程，以及社区版虚拟机管理能力。对于同时维护自建推理服务和传统服务器环境的开发团队，这些改动具有实际参考价值。官方资料并未证明所有硬件均可兼容，也不构成独立性能测试。升级前应核对驱动、主机环境及不同版本的功能限制。本次更新区别于 Radar #002 已报道的 1Panel 2.4。

**原始资料：**[1Panel 2.5.0 original release](https://github.com/1Panel-dev/1Panel/releases/tag/v2.5.0) · [1Panel v2 official changelog](https://1panel.pro/docs/v2/changelog/)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/1panel)

### 腾讯开源 LoopForge，支持团队级编码智能体与 SOP 研发流程

**原始发布日期：**2026-11-09

腾讯轻量云团队于 11 月 9 日介绍并开源 LoopForge，项目将 Docker 隔离的编码智能体工作区、团队共享角色、可复用 SOP 流程与人工审批节点结合。11 月 11 日发布的 v0.3.5 另行加入 Main Bot 轻量级 GitHub 操作、个人模型目录及流程修复。对开发团队而言，关键价值在于让智能体参与的软件交付过程可追踪、可审核，而非证明智能体能够在无人审查下安全上线。腾讯提供的内部使用数字尚无独立验证。

**原始资料：**[LoopForge v0.3.5 original release (Nov 11)](https://github.com/Tencent/LoopForge/releases/tag/v0.3.5) · [Tencent LoopForge original open-source engineering announcement](https://developer.cloud.tencent.com/article/2779233)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/loopforge)

## 开发者快讯

### Rspack 2.3.2 改进热更新依赖处理并引入实验性规则匹配

**原始发布日期：**2026-11-10

Rspack 2.3.2 调整代码分割场景下的热模块替换逻辑，在执行接受回调前加载新依赖的代码块，并减少部分不必要的更新传播。该版本还引入实验性的 \`rule.as\` 资源路径匹配，并改进对无副作用重导出模块的处理。这些调整有助于维护复杂依赖关系和自定义打包配置的前端团队。相关功能仍属实验性，官方更新说明也不等同于独立性能测评。

**原始资料：**[Rspack 2.3.2 original release](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.2)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/rspack)

### 美团以 MIT 协议开放 LongCat-2.5 模型权重

**原始发布日期：**2026-11-10

美团于 11 月 10 日单独发布 LongCat-2.5 的开源公告，采用 MIT 协议，并提供包含模型文件和部署说明的官方 Hugging Face 仓库。Radar #003 已介绍 11 月 2 日的技术架构，因此本次报道的新进展是模型权重与使用许可的对外开放，而不是新架构发布。根据官方说明，开发者可按适用许可条款进行商业推理部署与二次训练，但仍须自行核对仓库文件、许可证及硬件要求。模型文件的首次上传时间和独立性能评测未获确认。

**原始资料：**[Meituan LongCat-2.5 MIT open-source announcement](https://tech.meituan.com/2026/11/10/Meituan-LongCat-2.5-Open-Source.html) · [Official LongCat-2.5 model repository and MIT license](https://huggingface.co/meituan-longcat/LongCat-2.5)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/ai/longcat)

### 阿里低代码引擎 1.2.2 增加 ESM 组件元数据支持

**原始发布日期：**2026-11-13

阿里低代码引擎于 11 月 13 日发布 v1.2.2，增加组件元数据资源的 ES module 支持，并扩展引擎类导出。维护者还修复了导入 Schema 后的缓存判断问题，同时更新了文档与构建配置。对于维护自定义低代码编辑器及可复用组件物料的开发者，这些改动主要影响导入正确性和元数据格式支持。上述信息来自官方更新说明，并非独立兼容性或性能测试结果。

**原始资料：**[Alibaba Low-Code Engine original project repository](https://github.com/alibaba/lowcode-engine) · [Alibaba Low-Code Engine v1.2.2 release](https://github.com/alibaba/lowcode-engine/releases/tag/v1.2.2)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/alibaba-lowcode-engine)

### NocoBase v3 Beta 更新多实例配置与应用管理工具

**原始发布日期：**2026-11-09

NocoBase 于 11 月 9 日发布 v3 Beta 版本 2026-11-09.3，新增用于配置与验证共享 Redis 后端的多实例应用 Agent Skills，并增加应用基础层的启动扫描选项，同时改进数据库浏览器、移动端布局以及功能扩展的权限设置。这些改动适合评估 AI 辅助业务应用平台的团队关注，但该版本明确属于预发布测试版，不应称为 v3 稳定版。NocoBase 注册于新加坡，官方网站亦列有中国团队或业务联系地点。

**原始资料：**[NocoBase v3 Beta 2026-11-09.3 original release list](https://github.com/nocobase/nocobase/releases) · [NocoBase v3 beta original project and documentation](https://github.com/nocobase/nocobase)

### 研究札记：Ant Design 6.7.0 扩展组件配置与键盘无障碍操作

**原始发布日期：**2026-11-04

Ant Design 6.7.0 最初发布于 \*\*11 月 4 日\*\*。该版本为 Button、Tag、Steps、Alert、Timeline 等组件增加全局变体配置，扩展选择器和日期输入控件的后缀自定义，并加入清除按钮的键盘焦点顺序与无障碍名称配置等能力。其他调整还涉及 React 集成和选择交互。本文将其作为值得回顾的较早版本，而不是 W46 新发布内容。升级时应结合官方说明核对组件属性与兼容性。
