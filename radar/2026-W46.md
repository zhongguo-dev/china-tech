## Featured developments

### 1Panel 2.5.0 rebuilds GPU and vLLM operations for Linux servers

**Original publication:** 2026-11-11

1Panel's November 11 release reorganizes GPU, vLLM and model-service management within its Linux administration platform. The original notes describe GPU status and token-throughput views, model-service controls, MCP management, container update workflows and virtual-machine management in Community Edition. These changes are useful for operators combining self-hosted inference services with traditional server administration. The documentation does not establish universal hardware compatibility or independent performance gains; check your drivers, machine capabilities and edition-specific feature limits before upgrading. The release is distinct from the 1Panel 2.4 update covered in Radar #002.

**Original sources:** [1Panel 2.5.0 original release](https://github.com/1Panel-dev/1Panel/releases/tag/v2.5.0) · [1Panel v2 official changelog](https://1panel.pro/docs/v2/changelog/)

### Tencent open-sources LoopForge for team-based coding-agent workflows

**Original publication:** 2026-11-09

Tencent's Light Cloud team published its LoopForge open-source engineering introduction on November 9. The self-hosted project combines Docker-isolated coding-agent workspaces, shared team roles and reusable SOP workflows with explicit human approval gates. Its November 11 v0.3.5 release separately added lightweight GitHub actions for Main Bot, personal model catalogs and workflow fixes. For developer teams, the important change is reviewable coordination around coding agents rather than a claim that autonomous agents can safely ship unreviewed changes. Tencent's reported internal usage has not been independently verified.

**Original sources:** [LoopForge v0.3.5 original release (Nov 11)](https://github.com/Tencent/LoopForge/releases/tag/v0.3.5) · [Tencent LoopForge original open-source engineering announcement](https://developer.cloud.tencent.com/article/2779233)

## Quick updates

### Rspack 2.3.2 improves HMR chunk handling and adds experimental rule matching

**Original publication:** 2026-11-10

Rspack 2.3.2 updates hot module replacement behavior around split chunks, including loading newly required chunks before accept callbacks and avoiding some unnecessary update propagation. The patch also adds experimental \`rule.as\` resource-path matching and improves handling of side-effect-free re-exports. These changes may help frontend teams with complex dependency graphs and custom bundler configurations. The feature is experimental, and release notes are not independent evidence of measured performance improvements.

**Original sources:** [Rspack 2.3.2 original release](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.2)

**Related Directory entry:** [View on Zhongguo.dev](https://www.zhongguo.dev/projects/rspack)

### Meituan makes LongCat-2.5 weights available under MIT

**Original publication:** 2026-11-10

On November 10, Meituan published a separate open-source announcement for LongCat-2.5 under the MIT license and linked an official Hugging Face repository containing model artifacts and deployment documentation. This follows the model's engineering introduction on November 2, already covered in Radar #003. The new developer-facing development is the announced availability and licensing of reusable weights, not a new architecture. Commercial inference and further training are described as permitted under the stated license; teams should inspect the repository, license text and hardware requirements directly. The exact first upload time and any independent performance measurements were not verified.

**Original sources:** [Meituan LongCat-2.5 MIT open-source announcement](https://tech.meituan.com/2026/11/10/Meituan-LongCat-2.5-Open-Source.html) · [Official LongCat-2.5 model repository and MIT license](https://huggingface.co/meituan-longcat/LongCat-2.5)

### Alibaba Low-Code Engine 1.2.2 adds ESM component metadata support

**Original publication:** 2026-11-13

Alibaba Low-Code Engine released v1.2.2 on November 13, adding ES module support for component metadata resources and expanded engine-class exports. The maintainers also fixed a cache decision after importing a schema, alongside documentation and build updates. The patch matters to teams maintaining custom low-code editors and reusable component-material packages, particularly where import correctness and metadata formats are part of a tooling workflow. These are release-note changes, not independently tested compatibility or performance guarantees.

**Original sources:** [Alibaba Low-Code Engine original project repository](https://github.com/alibaba/lowcode-engine) · [Alibaba Low-Code Engine v1.2.2 release](https://github.com/alibaba/lowcode-engine/releases/tag/v1.2.2)

### NocoBase v3 beta improves multi-instance setup and application tooling

**Original publication:** 2026-11-09

NocoBase's November 9 v3 beta release 2026-11-09.3 introduced Agent Skills to help configure and verify multi-instance applications using a shared Redis backend. It also added a foundation startup-scan option and improved database-explorer and mobile layout behavior, while reorganizing permissions for features and extensions. These changes are relevant to teams evaluating AI-assisted business application platforms, but the cited version is explicitly a prerelease—not a stable v3 launch. NocoBase is Singapore-incorporated and documents team or operational locations in China.

**Original sources:** [NocoBase v3 Beta 2026-11-09.3 original release list](https://github.com/nocobase/nocobase/releases) · [NocoBase v3 beta original project and documentation](https://github.com/nocobase/nocobase)

### Research Desk: Ant Design 6.7.0 broadens component APIs and keyboard-accessible controls

**Original publication:** 2026-11-04

Originally released on November 4, Ant Design 6.7.0 added global component variants for Button, Tag, Steps, Alert and Timeline, expanded suffix customization across selection and date inputs, and introduced clearer keyboard-navigation and accessible-name controls for clear buttons. Other changes extend React integration and selection behavior. This is an earlier release worth examining for design-system migrations and accessible frontend interfaces, not a new W46 launch. Developers should consult the upstream compatibility notes before applying the new props.

**Original sources:** [Ant Design 6.7.0 original release](https://github.com/ant-design/ant-design/releases/tag/6.7.0) · [Ant Design maintainer changelog](https://github.com/ant-design/ant-design/blob/master/CHANGELOG.en-US.md)
