## Quick updates

### Rspack and Rsbuild 2.3 reach stable releases

**Original publication:** 2026-10-29

Both tools shipped stable 2.3 releases. This is a stable-availability follow-up to the beta coverage in Radar #001, not a claim that previously documented SWC Next and loader-filtering features first appeared this week. Rspack caching remains experimental.

**Original sources:** [Additional original source](https://github.com/web-infra-dev/rsbuild/releases/tag/v2.3.0) · [Original first-party source](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.0)

### deepin releases Linux 7.3 community preview packages

**Original publication:** 2026-10-27

Following the official upstream Linux 7.3 release, deepin released community preview packages for AMD64, ARM64 and Loong64. They are for manual testing, not a stable automatic system update; retain a fallback kernel and avoid production use.

**Original sources:** [Additional original source](https://bbs.deepin.org.cn/en/post/302598) · [Original first-party source](https://github.com/deepin-community/kernel/releases/tag/v25.01.01.01-v7.3.0)

**Related Directory entry:** [View on Zhongguo.dev](https://www.zhongguo.dev/projects/deepin)
