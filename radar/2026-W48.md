## Featured developments

### DiffSynth-Studio unifies multi-GPU inference and context compression

**Original publication:** 2026-11-23

The ModelScope community project announced unified parallel inference and configurable context compression on November 23. Current documentation describes sequence parallelism, distributing token computation across GPUs, and classifier-free guidance parallelism, distributing guidance branches across GPU groups. The two axes can be combined. Compression reduces the storage needed for intermediate tensors, reconstructing them when required; documented methods include EntroPack, SVD and Cholesky-QR, with model-specific support.

**Original sources:** [Context compression documentation](https://diffsynth-studio-doc.readthedocs.io/en/latest/Pipeline_Usage/KV_Cache_Compression.html) · [Maintainer announcement](https://github.com/modelscope/DiffSynth-Studio) · [Parallel inference documentation](https://diffsynth-studio-doc.readthedocs.io/en/latest/Pipeline_Usage/Parallel_Inference.html)

### GLM-5.4 becomes available through Z.ai Coding Plan

**Original publication:** 2026-11-23

ZCode 4.0.0 confirms GLM-5.4 availability and preconfiguration for Coding Plan users on November 23. The official changelog identifies visual input and broader coding capabilities as additions. Its developer FAQ also documents model selection in other Coding Plan clients, giving developers a concrete integration path.

**Original sources:** [ZCode developer FAQ](https://zcode.z.ai/en/docs/qa) · [ZCode official changelog](https://zcode.z.ai/en/changelog)

## Quick updates

### Apache Paimon 2.1.1 addresses lakehouse data correctness

**Original publication:** 2026-11-25

The November 25 release fixes commit-abort handling of reused compaction files, tag deletion, Iceberg snapshot metadata, REST rollback identity and Python compatibility. Automatic conflict rollback is disabled by default. The official catalog lists signed source distributions.

**Original sources:** [Apache official release catalog](https://release-catalog.apache.org/paimon/2.1.1/index.html) · [Upstream release notes](https://github.com/apache/paimon/releases/tag/release-2.1.1)

### Rspack 2.3.4 improves diagnostics and adds Solid v2 support

**Original publication:** 2026-11-24

The November 24 release removes unnecessary runtime helpers for compatible targets, adds plugin, loader and filename context to diagnostics, and supports Solid v2 through solid-loader and JavaScript/TypeScript starter templates. Cache and watch-mode fixes are also included.

**Original sources:** [Rspack upstream release](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.4)

**Related Directory entry:** [View on Zhongguo.dev](https://www.zhongguo.dev/projects/rspack)

### Ant Design 6.7.2 fixes component behavior and TypeScript declarations

**Original publication:** 2026-11-23

The November 23 patch addresses form labels for numeric field names, grouped-table default sorting, layout classes and custom prefixes, strict TypeScript optional-property declarations, and the native mixed state of indeterminate checkboxes.

### Research Desk: XXL-AI 1.7.0 restructures its agent harness

**Original publication:** 2026-11-22

The November 22 desktop release moves the session loop into a dedicated harness covering model requests, tools, MCP and skill loading. Session properties distinguish permission and human-interaction modes; scheduled tasks trigger sessions through a revised scheduler. Goal mode is reserved but not implemented.
