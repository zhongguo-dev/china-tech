## 重点技术进展

### DiffSynth-Studio 统一多 GPU 推理与上下文压缩

**原始发布日期：**2026-11-23

ModelScope 社区的 DiffSynth-Studio 于 11 月 23 日公布统一并行推理和可配置上下文压缩。当前文档介绍将 token 计算分配至多个 GPU 的序列并行，以及将引导分支分配至不同 GPU 组的无分类器引导并行。两种方式可组合。压缩机制减少中间张量的存储开销，并在需要时重建；文档涉及 EntroPack、SVD 和 Cholesky-QR 等方法，支持范围因模型而异。

**原始资料：**[Context compression documentation](https://diffsynth-studio-doc.readthedocs.io/en/latest/Pipeline_Usage/KV_Cache_Compression.html) · [Maintainer announcement](https://github.com/modelscope/DiffSynth-Studio) · [Parallel inference documentation](https://diffsynth-studio-doc.readthedocs.io/en/latest/Pipeline_Usage/Parallel_Inference.html)

### GLM-5.4 上线智谱 Coding Plan

**原始发布日期：**2026-11-23

ZCode 4.0.0 官方更新日志确认 GLM-5.4 于 11 月 23 日上线 Coding Plan 并完成预置配置，新增视觉能力及更广泛的编程能力。官方常见问题还介绍了其他 Coding Plan 客户端中的模型选择方式，为开发者提供实际接入路径。

**原始资料：**[ZCode developer FAQ](https://zcode.z.ai/en/docs/qa) · [ZCode official changelog](https://zcode.z.ai/en/changelog)

## 开发者快讯

### Apache Paimon 2.1.1 修复湖仓数据正确性问题

**原始发布日期：**2026-11-25

11 月 25 日发布的版本修复提交中止时复用的压缩文件处理、标签删除、Iceberg 快照元数据、REST 回滚标识及 Python 兼容性问题。冲突自动回滚默认关闭。官方目录提供签名源码包。

**原始资料：**[Apache official release catalog](https://release-catalog.apache.org/paimon/2.1.1/index.html) · [Upstream release notes](https://github.com/apache/paimon/releases/tag/release-2.1.1)

### Rspack 2.3.4 改进构建诊断并支持 Solid v2

**原始发布日期：**2026-11-24

11 月 24 日发布的版本为兼容目标减少不必要的运行时辅助代码，丰富诊断中的插件、加载器及文件名信息，并通过 solid-loader 和 JavaScript/TypeScript 模板支持 Solid v2，同时包含缓存与监听模式修复。

**原始资料：**[Rspack upstream release](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.4)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/rspack)

11 月 23 日发布的补丁修复数字字段名对应的表单标签、分组表格默认排序、布局类名及自定义前缀、严格 TypeScript 可选属性声明，以及不确定状态复选框的原生混合状态。
