## 重点技术进展

### Rspack 2.3 Beta：引入 SWC Next 解析与内存诊断能力

**原始发布日期：**2026-10-21

Rspack 2.3 Beta 引入基于 SWC Next 的 JavaScript 解析、按代码内容过滤 Loader、代码分割优化及构建与热更新内存诊断工具。后续 Beta.1 将新配置项从 filter.code 更名为 codeFilter。该系列仍处测试阶段，性能表现须结合实际项目验证。

**原始资料：**[Original source / 原始来源](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.0-beta.0) · [Original source / 原始来源](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.0-beta.1)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/rspack)

### OceanBase 4.2.5 CE BP8：增强备份安全与热点行处理

**原始发布日期：**2026-10-21

OceanBase 4.2.5 CE BP8 支持动态更新备份与归档访问凭据，增加可选的 GROUP\_COMMIT 热点行更新聚合优化，增强 MySQL 模式异步存储过程能力，并提高 CDC 提交时间戳精度。部署前应核对兼容性及升级路径限制。

**原始资料：**[Original source / 原始来源](https://github.com/oceanbase/oceanbase/releases/tag/v4.2.5_CE_BP8)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/oceanbase)

## 开发者快讯

### Rsbuild 2.2.14：新增 TanStack Start 项目脚手架

**原始发布日期：**2026-10-19

Rsbuild 2.2.14 稳定版本为 React 和 Solid 新增 TanStack Start 项目脚手架，并修复环境变量、PostCSS 配置发现、开发服务器和公共静态资源处理问题。

**原始资料：**[Original source / 原始来源](https://github.com/web-infra-dev/rsbuild/releases/tag/v2.2.14)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/projects/rsbuild)

### Rsbuild 2.3 Beta：新增 Lynx 模板与预览服务器生命周期接口

**原始发布日期：**2026-10-22

Rsbuild 2.3 Beta 新增 Lynx 脚手架、TypeScript 7 模板更新、可配置的大小报告和 onClosePreviewServer 钩子，同时升级至 Rspack 2.3 Beta。该版本仍需兼容性验证。

**原始资料：**[Original source / 原始来源](https://github.com/web-infra-dev/rsbuild/releases/tag/v2.3.0-beta.0)
