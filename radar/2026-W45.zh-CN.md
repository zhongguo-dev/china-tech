## 重点技术进展

### Atrex Kernel Agent 0.4.0 引入受监督的 GPU Kernel 优化流程

**原始发布日期：**2026-11-02

Atrex 0.4.0 引入 Light 工作流与模块化插件架构。独立 Supervisor 负责正确性检查、源码快照、同一资源下的 ABBA 延迟对比和候选实现验收。新版支持多文件源码和原生 CUDA 清单，并改进恢复机制；从 v0.3.0 升级需检查工作流与工作区兼容性。性能及 Token 节省数据均来自发布方。

**原始资料：**[Atrex technical release notes](https://github.com/alibaba/atrex-kernel-agent/blob/v0.4.0/docs/releases/v0.4.0.md) · [Atrex v0.4.0 original release](https://github.com/alibaba/atrex-kernel-agent/releases/tag/v0.4.0)

### 美团 LongCat-2.5 介绍可验证 Agent 训练与多模态基础设施

**原始发布日期：**2026-11-02

美团 11 月 2 日的 LongCat-2.5 技术报告介绍面向长程任务的原生多模态模型，包括复杂代码库开发。文章详述可执行编程任务构建、fail-to-pass 与 pass-to-pass 测试、异步部分轨迹强化学习，以及面向加速器的长上下文训推优化。性能与吞吐量为美团自测；此发布不同于 Radar #002 已报道的 AI Coding 文章。

**原始资料：**[Meituan LongCat-2.5 technical report](https://tech.meituan.com/2026/11/02/Meituan-LongCat-2.5.html)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/companies/meituan)

### 百度发布 ERNIE 5.5 Flash Base 权重与混合注意力架构

**原始发布日期：**2026-11-05

百度公开 ERNIE 5.5 Flash Base 的 FP8 与 BF16 预训练基座权重。该稀疏 MoE 模型总参数量 2800 亿，每 Token 约激活 140 亿参数，采用压缩注意力与部分完整上下文层，并提供 SGLang/vLLM 相关部署说明。128K 训练上下文不应与最高 1M 推理配置混淆。该模型不是指令微调聊天模型，权重采用专用许可；评测结果来自发布方。

**原始资料：**[Baidu model card and weights](https://huggingface.co/baidu/ERNIE-5.5-Flash-Base) · [ERNIE 5.5 Flash Base original release](https://ernie.baidu.com/release/ernie-5-5-flash-base)

**相关技术目录：**[在 Zhongguo.dev 查看](https://www.zhongguo.dev/zh/companies/baidu)

## 开发者快讯

### openEuler 发布面向 LTS 分支的 11 月维护与安全更新

**原始发布日期：**2026-11-04

openEuler 社区 Release、QA 与 CICD SIG 公布 update\_20261102 更新，覆盖 22.03-LTS-SP4 及多个 24.03 LTS SP 分支，列出软件包变更、安全公告及已知问题。管理员应核对所属分支与具体 CVE 信息，不应将不同分支的修复数量相加为独立漏洞总数。

**原始资料：**[openEuler development mailing list announcement](https://mailweb.openeuler.org/archives/list/dev%40openeuler.org/thread/5TXIJGN6NRLZEFX4O3UVWPHA7MJYCZY2/)

### 腾讯公布混元 Hy4 视觉理解与 Computer Use 能力

**原始发布日期：**2026-11-04

腾讯于 11 月 4 日公布混元 Hy4 的视觉理解和面向图形界面、命令行的 Computer Use 能力，并介绍了托管 API 接入方式。腾讯当时表示，模型权重及系统卡将在后续公开；不能把 API 可用等同于权重已经发布。性能与安全评价仍属发布方观点。

**原始资料：**[Tencent official Hy4 announcement](https://www.tencent.com/zh-cn/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/)
