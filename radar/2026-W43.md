## Featured developments

### Rspack 2.3 Beta Introduces SWC Next Parsing and Memory Diagnostics

**Original publication:** 2026-10-21

Rspack 2.3 beta adopts SWC Next for JavaScript parsing, introduces content-aware loader filtering, improves code splitting and adds tools to inspect memory retained during builds and hot updates. The beta.1 follow-up renames the new loader option from filter.code to codeFilter; this is a prerelease, and performance benefits require workload-specific verification.

**Original sources:** [Original source / 原始来源](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.0-beta.0) · [Original source / 原始来源](https://github.com/web-infra-dev/rspack/releases/tag/v2.3.0-beta.1)

### OceanBase 4.2.5 CE BP8 Improves Backup Security and Hot-Row Processing

**Original publication:** 2026-10-21

OceanBase 4.2.5 CE BP8 supports rotating backup/archive access credentials without changing the destination, adds optional GROUP\_COMMIT hot-row update aggregation, improves MySQL-mode asynchronous stored procedures and increases CDC commit timestamp precision. Operators should check compatibility and documented upgrade restrictions.

**Original sources:** [Original source / 原始来源](https://github.com/oceanbase/oceanbase/releases/tag/v4.2.5_CE_BP8)

### Rsbuild 2.2.14 Adds TanStack Start Scaffolding

**Original publication:** 2026-10-19

The stable Rsbuild 2.2.14 release adds TanStack Start scaffolding for React and Solid and fixes environment-variable behavior, PostCSS discovery, development-server issues and public asset handling.

**Original sources:** [Original source / 原始来源](https://github.com/web-infra-dev/rsbuild/releases/tag/v2.2.14)

### Rsbuild 2.3 Beta Adds Lynx Templates and Preview Lifecycle Support

**Original publication:** 2026-10-22

Rsbuild 2.3 beta adds Lynx scaffolding, updated TypeScript 7 templates, configurable size reporting and an onClosePreviewServer hook. It also upgrades to the Rspack 2.3 beta, so developers should treat this as a prerelease requiring compatibility testing.
