# China Tech

**English** | [简体中文](README.zh-CN.md)

**A curated guide to China's developer and open-source ecosystem.**

[Explore Zhongguo.dev](https://www.zhongguo.dev/) · [Browse the Directory](https://www.zhongguo.dev/directory) · [China Dev Radar](https://www.zhongguo.dev/radar) · [Suggest a project](https://github.com/zhongguo-dev/china-tech/issues/new/choose)

China Tech is a public, community-contributed reference maintained by [Zhongguo.dev](https://www.zhongguo.dev/). It helps developers explore technologies originating from China's developer ecosystem, with concise descriptions and links to primary sources.

The scope includes developer tools, open-source projects, frameworks, infrastructure, AI models, research, products and platforms, and developer-focused organizations. **Not every listed technology is open source.** Inclusion is for discovery and context, not endorsement, certification, or ranking.
