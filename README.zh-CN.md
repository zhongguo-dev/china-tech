China Tech 是由 [Zhongguo.dev](https://www.zhongguo.dev/zh) 维护的公开技术参考目录，帮助开发者发现中国开发者生态中的技术成果，并通过原始来源了解其背景与用途。

目录涵盖开源项目、开发工具、框架、基础设施、AI 模型、研究、产品与平台，以及与开发者相关的组织。**并非所有收录技术均为开源项目。** 收录仅供技术发现与参考，不代表质量认证、官方认可或排名。
